# 🎨 Hugging Face AI Image Generator

A simple AI image generation web application built with **Python, Streamlit, and Hugging Face Inference API**.

Users can enter a text prompt and generate high-quality AI images using a Hugging Face image-generation model.

## ✨ Features

- 📝 Text-to-image generation
- 🤗 Hugging Face Inference API
- 🎨 Simple and clean Streamlit UI
- ☁️ Sky-blue and white interface
- ⚡ No local AI model download required
- 🖼️ Generated image preview
- ⬇️ Download generated images
- 🔐 API token stored securely using `.env`

## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face Hub
- Hugging Face Inference API
- FLUX.1-schnell
- python-dotenv
